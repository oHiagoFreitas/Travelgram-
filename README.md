# Travelgram 🌍

Projeto de estudo em HTML e CSS, simulando uma landing page de rede social de viagens, com versão desktop e mobile responsiva.

Visualize online: **https://ohiagofreitas.github.io/Travelgram-/**

---

## 💻 Sobre o projeto

O **Travelgram** é um projeto de estudo que permite praticar a criação de landing pages responsivas. O site inclui:

- **Galeria de fotos** de destinos e experiências;  
- **Layout responsivo** para desktop e mobile;  
- **Seções de navegação** como Sobre, Destinos e Contato;  
- Estrutura visual organizada para treinar **hierarquia e experiência do usuário**.

O objetivo principal é consolidar conhecimentos de **HTML semântico, CSS moderno e design responsivo**.

---

## 🚀 Tecnologias utilizadas

- **HTML5**  
- **CSS3**

---

## 📚 O que aprendi/pratiquei

- Criação de **layouts responsivos**;  
- Estruturação de conteúdo em **cards e galerias**;  
- Boas práticas de **HTML semântico e CSS moderno**;  
- Ajustes de tipografia, cores e espaçamento para melhor experiência do usuário.
